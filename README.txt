人時売上予算比分析（PWA）

■ 公開のしかた（GitHub Pages）
1. GitHubで新しいリポジトリを作る（例：jinji-yosanhi）
2. このフォルダの中身（index.html ほか全部）をアップロード
3. Settings → Pages → Branch を main / (root) にして Save
4. 数分後に https://（アカウント名）.github.io/jinji-yosanhi/ で開けます

■ スマホのホーム画面に追加
・iPhone：Safariで開く → 共有ボタン →「ホーム画面に追加」
・Android：Chromeで開く → メニュー →「ホーム画面に追加」／「アプリをインストール」

■ 店長に送るPDF
画面の「店長に送るPDF」で「ブロック全体」か店舗を選び「PDFを作成」。
スマホでは作成後に出る「LINEなどで送る」からそのまま送れます。

■ 月ごとの保存と推移
読み込んだ月は自動で保存され、右上の「表示する月」で切り替えられます。
「推移」タブで年度ごとの月別推移が見られます（年度の始まりは「保存しているデータ」で変更）。
右上の「ログインして同期」からログインすると、データがクラウド（Firebase）に保存され、
スマホとPCで同じデータが見られます。ログインしなければ、その端末の中だけに保存されます。
念のため「保存しているデータ」→「バックアップを保存」でときどきバックアップを取ってください。

■ 使い方
本社のExcel（.xlsx）と日報CSVを画面にドロップ（スマホは「ファイルを選ぶ」）。
ログインしている場合は、井村さんのアカウントだけが読み書きできる場所に保存されます。
